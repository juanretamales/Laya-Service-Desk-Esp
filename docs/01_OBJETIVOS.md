# Objetivos
Evaluar Laya Multilingual original frente a Laya Multilingual fine-tuned en clasificación de tickets corporativos en español. Medir mejora de F1-macro, costos de entrenamiento y, finalmente, eficiencia y pérdida/ganancia de calidad tras cuantización post-training. No incluir Llama ni QLoRA como parte del experimento principal.
